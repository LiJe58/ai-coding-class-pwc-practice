# 수강생 실습 규칙

## 작업 범위

- 현재 `practice/workspace` 안에서 한 차시의 결과만 만듭니다.
- 답을 찾기 위해 상위 `student/` 체크포인트나 `instructor/complete`를 열거나 복사하지 않습니다.
- 강사가 요청하지 않으면 체크포인트 초기화·승격 명령을 실행하지 않습니다.
- `input/day-1`의 합성 CSV와 기존 Day 2 검토자료·사람 검토 기록을 보존합니다.
- 실제 회사자료, 개인정보, 비밀값과 운영 URL을 추가하지 않습니다.

## 고정 업무 기준

- Day 1 집계는 전체 30건, 유효 29건, 정상 21건, 검토 필요 8건, 입력 오류 1건입니다.
- Day 2 표본은 `CHG-2608-001`~`004`, `CHG-2608-022`~`029`의 12건입니다.
- 고정 규칙, Agent가 작성한 초안과 사람이 입력한 최종 결론을 서로 덮어쓰지 않습니다.
- 사람 검토는 `U701`만 저장할 수 있고 `U601`은 거부되어야 합니다.
- Agent 근거 확인도 `U701`은 성공하고 `U601`은 거부되어야 하며 실행 이력은 사람 검토와 분리해 저장합니다.
- 같은 저장 요청은 한 번만 기록하고, 결론 수정은 이전 기록을 남긴 채 새 이력으로 추가합니다.
- 사람 결론은 현재 Agent 검토자료의 생성 시각과 `change_id`가 모두 같은 기록만 사용합니다.

## 구현과 확인

- Day 1~3 차시는 `internal-control-lab` Skill의 순서로 진행합니다.
- 현재 코드와 호출 경로를 조사한 뒤 변경 파일과 화면 결과를 먼저 설명합니다.
- 기존 React, FastAPI, SQLite와 설치된 패키지를 재사용합니다. 모델 호출은 공식 OpenAI SDK만 사용합니다.
- Agent 설정은 `OPENAI_API_KEY`, `OPENAI_MODEL`, 선택적 `OPENAI_BASE_URL` 환경변수에서만 읽고 응답이나 로그에 값을 남기지 않습니다.
- 동작이 바뀌면 기존 `test_checkpoint.py`에 꼭 필요한 검사만 추가하며 기존 검사를 삭제하거나 약하게 만들지 않습니다.
- 구현 후 `npm run check`와 관련 API를 실제로 확인합니다. 실행하지 않은 항목은 통과로 보고하지 않습니다.
- 백엔드는 `npm run start:backend`, 프런트엔드는 `npm run dev:frontend`, MCP 단계는 `npm run start:mcp`로 실행합니다.
