# Internal Control Lab

1. 현재 차시, 시작 상태, 화면·API·데이터의 완료 기준을 확인합니다. 시작 상태가 다르면 코드를 바꾸거나 초기화하지 말고 차이를 먼저 알립니다.
2. 관련 코드와 호출 경로만 조사하고 변경할 파일과 사용자가 보게 될 결과를 설명합니다.
3. 동작이 바뀌면 기존 `test_checkpoint.py`에 핵심 결과를 확인하는 검사 하나를 먼저 추가합니다. 조사나 문서 작업에는 테스트를 만들지 않습니다.
4. 기존 구조와 설치된 패키지를 재사용해 가장 작은 범위로 구현합니다.
5. `npm run check`와 이번 차시의 대표 API 또는 화면을 확인합니다.
6. 실제 결과, 실패한 검사, 다음 차시가 이어서 사용할 파일·API·상태를 짧게 보고합니다.

실제 회사자료·비밀값이 필요하거나 판정·권한 기준이 불명확하면 중단하고 강사에게 확인합니다.
